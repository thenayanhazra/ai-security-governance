# Changelog

All notable changes to this governance kit are documented here.

## [1.0.0] - 2026-11-26

### Phase 3 — Governance-as-Code & Ecosystem Glue
- Moved KRIs (`data/kris.yaml`) and reference threats (`data/threats.yaml`) into YAML single sources of truth generated by `tools/build.py`.
- Added JSON Schemas (`schemas/controls.schema.json`, `schemas/kris.schema.json`, `schemas/threats.schema.json`).
- Emitted machine-readable exports: `dist/governance.json` (for `ai-security-assessment` and downstream tools) and `dist/oscal-catalog.json` (NIST OSCAL 1.1.2 Catalog).
- Added interactive client-side control applicability filter (`docs/control-selector.html`) and 30/60/90-day adoption playbook & maturity rubric (`docs/adoption-playbook.md`).
- Added engineering starter kits: OPA/Rego reference policy (`examples/opa/`), zero-dependency MCP tool-definition fingerprinting CLI (`examples/mcp-fingerprint/`), and CI governance gate workflow (`examples/ci/ai-governance-gate.yml`).
- Added `pyproject.toml`, `CONTRIBUTING.md`, `pytest` unit test suite (`tests/`), and expanded CI checks in `.github/workflows/validate.yml`.

### Phase 2 — Operational Templates, Policies, Runbooks & Controls
- Expanded control catalogue from 34 to 40 controls (`GOV-05`, `SUP-04`, `INP-04`, `DAT-03`, `DAT-04`, `TST-04`).
- Added `T-18`–`T-20` to the reference threat model (20 threats) and `KRI-13` (overdue risk exceptions, 13 KRIs).
- Added ready-to-adopt Enterprise AI & Acceptable Use Policy (`policies/enterprise-ai-policy.md`), operational templates (`templates/`), and kill-switch & AI incident response runbooks (`runbooks/`).

### Phase 1 — Correctness, Crosswalk Honesty & Validator Hardening
- Added `or_impact` control applicability triggers so tier 0–1 high/severe impact systems (including EU AI Act high-risk advisory systems) trigger required controls.
- Completed `data/references.yaml` with all 72 NIST AI RMF 1.0 subcategories, all 38 ISO/IEC 42001 Annex A controls, 21 EU AI Act articles, and 28 in-scope MITRE ATLAS techniques; added MITRE ATLAS reverse crosswalk and per-framework coverage counts.
- Fixed KRI threshold boundary overlaps and aligned the Q3 worked board report `KRI-05` figure (`72 min`) with the Red threshold (`> 60 min`).
- Routed code sandbox and inter-agent delegation through the policy enforcement layer in the threat model architecture diagram.
- Synced open-source `tooling:` mappings with `ai-security-assessment` and upgraded `tools/validate.py` to verify `or_impact`, `references.yaml` ATLAS IDs, Markdown heading anchors, and in-prose control IDs.

## [0.1.0] - 2026-11-12
- Initial release: AI and agent risk framework, 34 controls, crosswalk, board pack, 12 KRIs, reference threat model, MCP supply-chain policy, regulatory horizon, and build/validate pipeline.
